# Native plugins

External plugins remain canonical upstream. These commands document explicit
individual installation; Agent Toolkit does not run them automatically.

## humanizer

Writing cleanup that targets mechanical AI patterns.

- Upstream: [blader/humanizer](https://github.com/blader/humanizer)
- Install:

  ```bash
  copilot plugin marketplace add blader/humanizer
  copilot plugin install humanizer@humanizer
  ```

## cli-printing-press

Structured writing workflows from the command line.

- Upstream: [mvanhorn/cli-printing-press](https://github.com/mvanhorn/cli-printing-press)
- Install:

  ```bash
  copilot plugin install mvanhorn/cli-printing-press
  ```

## mattpocock-skills

Planning, research, prototyping, and engineering workflows.

- Upstream: [mattpocock/skills](https://github.com/mattpocock/skills)
- Install:

  ```bash
  copilot plugin install mattpocock/skills
  ```
