## Resolved identities

- Gog CLI is `openclaw/gogcli`, formerly `steipete/gogcli`. It is not the
  separate Google Workspace CLI with the `gws` command.
- `xurl` is the agent-oriented URL client from `Xuanwo/xurl`. It is not the
  unrelated X API CLI.
- Cua Driver is a subproject in the `trycua/cua` monorepo.
- Obsidian CLI is an official feature of the proprietary Obsidian application,
  not an independent open-source project.

## Open licensing fact

The Microsoft Learn CLI package declares MIT in its package metadata, while its
repository root is licensed under CC-BY-4.0. The catalog can link to the tool,
but it must not state one unqualified project-wide license until Microsoft
clarifies the distribution-level license.
